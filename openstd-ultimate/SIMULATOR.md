# Laboratorio simulado OpenSTD Ultimate

Abrir `simulator.html` en cualquier navegador moderno. No requiere instalar software.

## Escenarios interactivos
- Equipo sin alertas
- Sobrecalentamiento
- SSD con advertencia
- Batería degradada

El dashboard muestra valores **100 % ficticios**, indicadores, un gráfico de ejemplo, acciones sugeridas y un informe JSON marcado `SIMULACION_NO_CERTIFICADA`. No solicita permisos, no lee hardware, no hace pruebas reales y no transmite datos.

Este laboratorio permite validar la experiencia visual antes de integrar sensores reales. Los números no deben emplearse para diagnósticos ni certificaciones.
