# OpenSTD Ultimate — MVP UI/UX

Prototipo independiente para evolución de OpenSTD. **No es un fork ni una modificación del proyecto original.**

## Ejecutar
Abrir `openstd-ultimate/index.html` en un navegador moderno. No requiere instalación ni dependencias.

## Disponible
- Dashboard responsive oscuro y navegación por módulos.
- Catálogo de pruebas planificadas.
- Vista de sensores con estados explícitos sin datos.
- Bitácora local con almacenamiento en el navegador.
- Informe preliminar imprimible de observaciones.

## Pendiente
- Evaluar licencia y arquitectura del OpenSTD original antes de reutilizar código.

- Agregar tests automatizados, seguridad, consentimiento y límites térmicos.

## Seguridad
No simula resultados clínicos/técnicos ni afirma que un equipo está sano. No sube información. Las notas quedan en el navegador local.
